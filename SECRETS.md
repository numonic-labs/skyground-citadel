# Secrets

There are things in Skyground Citadel that nothing on screen points at. Find one and tell us.

## What there is

- **Two in the game.** You find them by playing. When you do, the game says a short line of words.
- **One in the code.** `node tools/riddle.mjs` asks a question that can only be answered by running the game's rules.

The finish card counts the two in the game. More will be added as the game grows.

## Telling us

- Join the Discord: https://discord.gg/tejSd5SkeD
- **Do not post the words or the answer in a public channel.** Say that you found something, and send the details in a
  direct message to a Numonic moderator, with how you found it. A secret that is posted in public is spoiled for everyone,
  and a spoiled secret earns nothing.
- Reading the source to find the in-game secrets is allowed. The level data and the words are in plain sight on purpose.
  Tell us that is how you did it; it counts as a find, of the developer kind.

## What a find earns

Access and recognition, never money or prizes.

| Find | What it earns |
| --- | --- |
| Either secret in the game | A viewer account in the Skyground Citadel library, where the game's assets are published |
| Both secrets in the game | You can upload to the library's submissions collection |
| The riddle in the code | Your pull requests are looked at first, and you can upload to the submissions collection |

"Looked at first" means read and answered sooner. It does not mean merged: a pull request is merged when it is good for the
game. Access is given by a person, usually within a week, and can be withdrawn if it is misused.
